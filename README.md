# EndyOS

**EndyOS** is a custom Android project focused on improving and refining the Xiaomi HyperOS experience.

The main goal of EndyOS is to provide a cleaner, smoother, and more customizable system while keeping the core Xiaomi experience intact. Instead of completely changing how HyperOS works, EndyOS focuses on carefully selected modifications, optimizations, additional features, and system-level improvements.

The project is built with stability and daily usability in mind. Changes are tested as much as possible before being included, and unnecessary modifications are avoided when they do not provide a real benefit.

## ✨ What EndyOS Focuses On

* System optimization and performance improvements
* HyperOS feature enhancements
* Additional customization options
* Removal or reduction of unnecessary system components
* Improved system behavior and usability
* Carefully selected China ROM features where possible
* System application and framework modifications
* Visual improvements and EndyOS branding
* Maintaining a balance between features, performance, and stability

## 📱 Compatibility

EndyOS is mainly developed and tested around Xiaomi / Redmi devices.

Device support, Android versions, installation requirements, and available features may differ between releases. Always check the release notes and installation instructions before flashing anything.

## 🛠️ Development

EndyOS is an evolving project.

Features, optimizations, overlays, framework modifications, system applications, and other components may change as development continues. Some experimental changes may be introduced, reworked, or removed depending on their stability and usefulness.

Feedback and bug reports are always useful, especially when they include detailed information such as:

* Device model

* Android / HyperOS version
